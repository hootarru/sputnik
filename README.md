## Как устроена вёрстка

- **≥ 1024px — артборд.** Каждая секция — кусок фрейма 1440 с абсолютным позиционированием по координатам Figma (`at(x, y, w)` в `src/lib/at.js`). Все размеры, включая кегли, умножаются на `--s = min(100vw, 1440px) / 1440`, поэтому композиция и переносы строк совпадают с макетом от 1024 до 1440. Шире 1440 — масштаб 1, артборд по центру, полосы (навбар, лайм в подвале) на всю ширину.
- **< 1024px — поток.** Порядок DOM = порядок чтения; раскладка задаётся в CSS каждой секции. 640–1023 — планшет (асимметричные отступы, две колонки карточек, «лесенка» шагов), < 640 — телефон.
- **Тексты** — `src/content.js`, дословно из Figma, включая неразрывные пробелы.
- **Калибровка** — `src/styles/calibration.css`: Inter в Figma немного шире Inter 4.0 в браузере, поэтому для отдельных заголовков и абзацев трекинг сдвинут на доли процента, чтобы строки рвались как в макете. Подобрано автоматическим сравнением со скриншотом Figma.

## Структура

```
src/
  App.jsx, main.jsx
  content.js            тексты из Figma
  config.js             внешние ссылки (бот, Telegram, ВК)
  lib/at.js             координаты артборда
  components/           Navbar, Hero, About, Audience, Scenarios, SafeSpace, HowItWorks, FinalCta, Footer,

```

Плавная прокрутка — CSS `scroll-behavior` + `scroll-padding-top: 56px` (высота навбара). На телефоне (< 720px) пункты меню в выпадающей панели «меню».

## Анимации

GSAP + ScrollTrigger, только при `prefers-reduced-motion: no-preference`.
Скрытые стартовые состояния задаёт только GSAP; если он не загрузился или упал, страница остаётся статичной и полностью видимой. Все твины в конце очищают inline-стили — итоговая композиция совпадает с Figma.

- Hero: «СПУТНИК» проявляется, лаймовая полоса «проводится маркером», затем слоган и нижние блоки.
- Персонаж в hero: лапки машут волной (асинхронно), глаза моргают, зрачки следят за курсором, на наведение — «привет».
- Секции: номер и заголовок поднимаются вместе, плашка номера раскрывается слева направо, курсив — с задержкой.
- Коллажи 02: фото появляются по очереди с разным сдвигом; карточки 03 и шаги 05 — последовательно, лаймовые шапки раскрываются.
- CTA: заголовок → маркерные плашки → подзаголовок и кнопка. Персонаж в подвале поднимается, дотягивается лапками до кнопки и периодически «нажимает» её; при наведении на кнопку тянется сильнее.
